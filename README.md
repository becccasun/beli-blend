# Beli feature proposal

A coded prototype exploring three feature ideas for the Beli restaurant ranking app. This is an unofficial student concept. It is not affiliated with or endorsed by Beli, and all people, scores and activity in it are made up.

**Live demo:** https://becccasun.github.io/beli-proposal/

## What is in it

1. **Flexible rating**: when you rank a place, keep the familiar head to head comparison or set the score yourself, with a live preview of where it lands on your list. Open any restaurant and tap "Rank this place".
2. **Team challenges**: take on a challenge with friends, see everyone's scores per spot, nudge teammates, and earn leaderboard points together. Open the Team challenges card on the feed.
3. **Blend**: mix your rankings with a friend or two to get one shared list of where to eat. Open the Blend card on the feed.

## Run it locally

```bash
npm install
npx next dev -p 3012
```

Built with Next.js and Tailwind. Everything is mock data stored in the browser, so there is no backend.
